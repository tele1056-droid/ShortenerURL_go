# Инкремент 5. Конфигурация через переменные окружения
**env-**(т environment) — окружение, среда

## Что сделано
- В пакет `config` добавлена поддержка переменных окружения `SERVER_ADDRESS` и `BASE_URL`.
- Обновлена функция `NewConfig()`: после чтения флагов она проверяет переменные окружения и, если они заданы, перезаписывает значения.
- Приоритет настроек: env > флаг > значение по умолчанию.

## Зачем
- **12-factor app:** Использование переменных окружения — стандарт для конфигурации приложений в облаках и контейнерах (Docker, Kubernetes).
- **Гибкость:** Позволяет менять настройки без изменения командной строки (удобно для CI/CD).

## Проблемы и решения
- **Проблема:** В Windows синтаксис передачи env-переменных отличается от Linux.
- **Решение:** Использую Git Bash (UCRT64), где работает стандартный синтаксис `VAR=value command`.

## Какой пакет использовать, встроенный или сторонний (caarlos0/env)?
Для инкр.5 лучше использовать встроенный os.Getenv - это проще, быстрее и полностью соответствует заданию, и стандартного пакета достаточно для вып. инкр.
А сторонний пакет caarlos0/env становится полезен, когда десятки переменных окружения и нужно автомат. парсить их в структуры с валидацией. Но для развития проекта этот пакет рекоменд. платформой.

## Нюанс для Windows
В Windows (особенно в CMD или PowerShell) синтаксис установки переменных окружения перед командой отличается от Linux/macOS.

- **Bash (Git Bash, WSL): у себя в терминале (терм. с bash) исп. этот варинт**
  SERVER_ADDRESS=localhost:9999 go run ./cmd/shortener

- **PowerShell:**
  $env:SERVER_ADDRESS="localhost:9999"; go run ./cmd/shortener

- **CMD:**
  set SERVER_ADDRESS=localhost:9999 && go run ./cmd/shortener


# Как это проверить (все из корня проекта):
## 1.Только флаги:
go run ./cmd/shortener -a localhost:8888 -b http://myurl.com
Сервер запустится на localhost:8888, ответы будут с http://myurl.com.

## 2.Переменные окружения перебивают флаги:
SERVER_ADDRESS=localhost:9999 BASE_URL=http://envurl.com go run ./cmd/shortener -a localhost:8888
Сервер запустится на localhost:9999 (из env), ответы будут с http://envurl.com (из env). Флаги проигнорированы.

## 3.Только переменные окружения (без флагов):
SERVER_ADDRESS=localhost:9999 go run ./cmd/shortener
Сервер запустится на localhost:9999, BaseURL останется дефолтным (http://localhost:8080).
