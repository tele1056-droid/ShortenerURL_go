# Инкремент 9. Сохранение данных в файл (JSON Lines)

## Что сделано
- Изменён формат файла: теперь каждая строка — отдельный JSON-объект с полями `uuid`, `short_url`, `original_url`.
- Создана структура `URLRecord` для сериализации.
- Обновлён `FileStorage`:
  - При загрузке читает файл построчно (JSON Lines).
  - При сохранении дописывает новую строку в конец файла.
- В `config.go` изменено значение по умолчанию для `-f` на `/tmp/short-url-db.json`.
- При пустом `FILE_STORAGE_PATH` используется `MemoryStorage` (запись на диск отключена).

## Зачем
- **Персистентность:** Данные не теряются при перезапуске сервера.
- **Читаемый формат:** JSON Lines удобен для ручного просмотра и отладки.
- **Гибкость:** Можно отключить запись на диск, передав пустой путь.

## Проблемы и решения
- **Проблема:** Старый формат файла (map) не совместим с новым (JSON Lines).
- **Решение:** При загрузке старые данные игнорируются (или можно добавить миграцию, но для учебного проекта это не требуется).

## Главное изменение - формат файла.
 Теперь это JSON Lines (каждая строка — отдельный объект). Вам нужно обновить FileStorage, чтобы он читал и писал в этом формате.
