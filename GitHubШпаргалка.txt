По началу на гитхаб аккаунте tele1056-droid, располагается репозиторий yandex_lyceum_self_paced_go, в нём папка (проект) projectsYA.
    Аккаунт: tele1056-droid
    └── Репозиторий: yandex_lyceum_self_paced_go
        └── Папка: projectsYA

И для отдельных проектов на аккаунте гитхаб лучше создавать отдельные репозитории, и допустим если без создания нового репозитория коммитить и пушить изменения в проекте "projects" то они будут отражаться в репозитории yandex_lyceum_self_paced_go - это желательнее делать если разные проекты как-то между собой связаны.

Нужно сделать вот такую структуру на гитхаб:
Аккаунт: tele1056-droid
├── Репозиторий: yandex_lyceum_self_paced_go
│   └── Папка: projectsYA
└── Репозиторий: projects
    └── (файлы projects)

В данном случае два независимых репозитория.

Как создать новый репозиторий:
1. Зайдите на GitHub → New repository.
2. Дать название репозиторию.
3. Не ставить галочку «Add a README» (чтобы не было конфликта).
4. И нажать Create repository.

И затем в терминале в папке projects, в дальнейшем изменить на ShortenerURL:
То есть команды ниже - это инициализация нового репозитория. Перед этим лучше перейти в папку проекта который хотим добавить в новый репозиторий на гитхаб и командой "git remote -v" проверить не находимся ли в старом репозитории.

Инициализация нового репозитория:
git init
git add .
git commit -m "Начальная версия"
git remote add origin https://github.com/tele1056-droid/projects.git
git push -u origin main
